## PHASE III: THE ADVERTISING PSYCHOLOGY PLAYBOOK

*Direct application of JOUR 4251 frameworks*

### 3.1 Functions of Advertising (Ch. 1)
- **INFORM**: BlackRoad exists, runs on Pis, costs $40/month, is OpenAI-compatible
- **PERSUADE**: Your AI should be yours. The session boundary is broken. Memory is the moat.

### 3.2 Hard-Sell vs Soft-Sell (Ch. 1)
- **Hard-sell (Alpha strategies — approach motivation)**:
  - "Switch from OpenAI in one line of code"
  - "15 models, $5/month, your hardware"
  - Technical docs, benchmarks, API reference

- **Soft-sell (Omega strategies — avoidance motivation)**:
  - "What happens to your conversations when OpenAI decides to change their terms?"
  - "Your AI identity shouldn't live on someone else's server"
  - Emotional storytelling about sovereignty and identity

### 3.3 Attitude Formation (Ch. 3/4)
Three components to target:
- **Cognitive** (beliefs): "Local AI is as good as cloud AI" — prove with benchmarks
- **Affective** (feelings): "It feels good to own your AI" — brand aesthetic, design system
- **Behavioral** (actions): "I already use it daily" — self-perception theory (use → believe)

### 3.4 Memory & Attention (Ch. 2/3)
- **Semantic memory**: BlackRoad = sovereign AI (establish the category link)
- **Episodic memory**: "Remember when you had to re-explain everything to ChatGPT?" (create the pain memory)
- **Priming**: Spectrum gradient, "Pave Tomorrow", road metaphors — create associative network
- **Forgetting**: Repetition across all 30+ websites prevents decay. Ecosystem footer on every page.

### 3.5 ELM Dual Processing (Ch. 5)
- **Central route** (developers — high ability, high motivation):
  - Detailed API docs, performance benchmarks, architecture diagrams
  - "Here's exactly how it works" — stable attitude change
- **Peripheral route** (casual users — low motivation to evaluate):
  - Clean design, familiar chat UI, social proof
  - "Looks like ChatGPT but it's mine" — quick adoption via heuristics

### 3.6 Theory of Planned Behavior (Ch. 6)
To get users to SWITCH:
- **Behavioral beliefs** → "Switching is easy" (one-line code change)
- **Normative beliefs** → "Smart devs self-host" (social proof)
- **Efficacy beliefs** → "I CAN run my own AI" (tutorials, Pi kit guide)

### 3.7 Automaticity & Habits (Ch. 6)
- **Brand loyalty**: Once habit forms around BlackRoad Chat, past behavior predicts future behavior
- **Goal-dependent automaticity**: Make daily AI use → automatic → BlackRoad
- **Ego depletion**: When users are tired/busy, they reach for what's familiar → be that familiar thing

### 3.8 Compliance Principles (Ch. 7)

| Principle | BlackRoad Application |
|-----------|----------------------|
| **Reciprocity** | Free tier → users feel obligation to upgrade. Give before asking |
| **Commitment/Consistency** | Free account → save conversations → memory → can't leave (foot-in-the-door) |
| **Social validation** | "X developers switched this month" counter on landing page |
| **Liking** | Agent personas (Alice, Cecilia, etc.) create parasocial connection |
| **Authority** | Delaware C-Corp, real infrastructure, open source code = legitimacy |
| **Scarcity** | "Founding Member" tier for first 500 users |
| **Door-in-the-face** | Show Enterprise pricing first ($200/mo) → Navigator ($10) feels cheap |

### 3.9 Personalization (Ch. 13)
- **Self-referencing**: "YOUR AI identity twin" — not "an AI" but "YOUR AI"
- **Privacy calculus**: Benefits (memory, continuity, sovereignty) must outweigh costs (setup, learning curve)
- **Personalization paradox**: Show personalization is empowering, not surveilling
  - GOOD: "Your AI remembers your coding preferences"
  - BAD: "We tracked 47 conversations about your anxiety"

### 3.10 Packaging (Ch. 14)
- **Silent salesperson**: The design system IS the packaging
  - Black background = premium, technical
  - Spectrum gradient = dynamic, alive, multi-dimensional
  - Space Grotesk = modern, clean, not generic
  - JetBrains Mono = developer credibility
- **Embodied cognition**: The FEEL of blackroad.io should evoke "sovereign, powerful, mine"
- **Shape associations**: Road metaphor = journey, progress, forward motion

### 3.11 Diversity & Segmentation (Ch. 12)
- **Subcultures**: Privacy community, self-hosting community, developer community, creator community — each has different values and norms
- **Consumer socialization**: First users teach their communities → organic growth
- **Intergenerational**: Developer → team → company adoption chain
