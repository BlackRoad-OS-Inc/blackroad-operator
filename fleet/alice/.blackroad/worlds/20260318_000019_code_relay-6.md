```python
def remove_duplicates(input_list):
    """
    Removes duplicate values from a given list while maintaining the original order.
    
    Args:
        input_list: A list of elements that may contain duplicates.
    
    Returns:
        A new list with duplicates removed and original order preserved.
    """
    seen = set()
    result = []
    for item in input_list:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result
```
