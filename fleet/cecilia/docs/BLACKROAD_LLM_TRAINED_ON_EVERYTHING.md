## 🔬 TECHNICAL DETAILS

### Corpus Building Process
1. **Discovery**: Scan filesystem for relevant files
2. **Filtering**: Skip node_modules, .git, etc.
3. **Prioritization**: Score files by keywords (BlackRoad, quantum, agent)
4. **Processing**: Read top 1,000 files
5. **Chunking**: Split into 512-token examples
6. **Sampling**: Create 1,000 training examples

### Training Process
1. **Tokenization**: Build 8,000-word vocabulary
2. **Model Creation**: 3-layer transformer (2.7M params)
3. **Device Selection**: Apple MPS (Metal Performance Shaders)
4. **Optimization**: AdamW with φ-based learning rate decay
5. **Training Loop**: 10 epochs, 16 batch size
6. **Validation**: Test generation on prompts

### Inference Process
1. **Tokenize input**: Convert text to IDs
2. **Forward pass**: Through 3 transformer layers
3. **Predict next**: Argmax over vocabulary
4. **Decode**: Convert IDs back to text
5. **Generate**: Repeat for desired length
