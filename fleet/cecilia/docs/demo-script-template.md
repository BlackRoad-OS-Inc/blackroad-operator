## 🎨 Visual Style Guide

### Color Palette
- **Primary:** Hot pink (#FF1D6C)
- **Secondary:** Violet (#9C27B0)
- **Accent:** Electric blue (#2979FF)
- **Background:** Deep black (#000) to purple (#1a0033)

### Typography
- **Headings:** SF Pro Display, Bold
- **Body:** SF Pro Text, Regular
- **Code:** SF Mono, Regular

### Animations
- **Duration:** 200-400ms
- **Easing:** ease-out
- **Style:** Smooth, professional
- **Brand:** Gradient glows, particle effects

### Music
- **Tempo:** 120-140 BPM
- **Style:** Electronic, uplifting
- **Volume:** Background, not distracting
- **Vibe:** Futuristic, professional

## 📹 Recording Checklist

### Pre-Production
- [ ] Write full script
- [ ] Create storyboard
- [ ] Design all graphics
- [ ] Record voiceover
- [ ] Source music (royalty-free)

### Production
- [ ] Record screen captures (1920x1080)
- [ ] Use smooth mouse movements
- [ ] Capture UI interactions
- [ ] Record multiple takes
- [ ] Get B-roll footage

### Post-Production
- [ ] Edit in sequence
- [ ] Add animations
- [ ] Color grade
- [ ] Mix audio
- [ ] Add captions
- [ ] Export at 1080p, 60fps

### Formats Needed
- **Full:** 60s for YouTube/website
- **Short:** 30s for Twitter/LinkedIn
- **GIF:** 15s for Product Hunt
- **Square:** 1:1 for Instagram

## 🎬 Tools Recommended

### Screen Recording
- **macOS:** QuickTime (free)
- **Windows:** OBS Studio (free)
- **Advanced:** ScreenFlow ($149)

### Video Editing
- **Beginner:** iMovie (free)
- **Intermediate:** DaVinci Resolve (free)
- **Pro:** Final Cut Pro ($299) or Adobe Premiere

### GIF Creation
- **macOS:** LICEcap (free)
- **Any platform:** ezgif.com (online)
- **Quality:** Gifski (free, macOS)

### Animation
- **Web:** Canva (free tier)
- **Advanced:** After Effects (subscription)
- **Code:** Remotion (React-based)
