Context Bridge makes it effortless to share your codebase with AI coding assistants.

• Export single files or entire folders

• Fast: Handle projects with 1000+ files

🎯 PERFECT FOR
• Getting AI help with debugging complex issues
• Code reviews with AI assistance
• Architecture discussions and refactoring
• Documentation generation
• Learning new codebases faster
• Pair programming with AI

1. Right-click any file or folder in VS Code or your file browser
2. Select "Export to Context Bridge"
3. Context is formatted and copied to clipboard
4. Paste into Claude, BlackRoad OS, or any AI assistant
5. Get instant, context-aware help!
