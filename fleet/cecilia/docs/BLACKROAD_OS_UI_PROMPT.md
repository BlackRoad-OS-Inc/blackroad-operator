## CANONICAL PROMPT (Copy-Paste Ready)

```
Create a high-fidelity mockup of a web-based Agentic Operating System interface called "BlackRoad OS, Inc."

STYLE & VIBE:
- Dark mode, professional, futuristic but warm
- Feels like a real operating system, not a SaaS dashboard
- Combines developer tools, command centers, and collaborative AI agents
- Clean, sharp UI with a subtle neon rainbow gradient accent (orange → pink → purple → blue)
- Serious, credible, and investor-ready — not playful or cartoonish

TOP NAVIGATION BAR:
Include a top navigation bar with the following tabs:
- Dashboard
- Repositories
- Files
- Terminal
- Tools
- Agents

LEFT PANEL (Chat / Planning Interface):
A vertical panel titled:
"Chat / Coding / Planning Interface"

Inside the panel, list multiple AI agents with short placeholder messages, for example:
- Cecilia
- Cadence
- Lucidia
- Octavia
- Aria
- Anastasia
- Alice
- Gematria
- BlackRoad OS
- Silas
- Alexandria
- Alexa Louise (the human operator)

At the bottom of this panel, include a command-style input prompt (e.g. >>>) to imply direct control and execution.

CENTER WORKSPACE:
The main central area should show a large, immersive command workspace:
- A futuristic control room or operations center
- Large monitors, desks, and a circular or collaborative layout
- Feels like an AI operations hub or mission control
- High detail, cinematic lighting, realistic but stylized

RIGHT PANEL (Worlds / Environments):
A grid of smaller panels showing pixel-art environments in a 16-bit / Pokémon-style aesthetic, such as:
- Office interiors
- Labs
- Meeting rooms
- Outdoor campus spaces
- A central plaza or garden

These represent different "agent worlds" or workspaces inside the OS.

TERMINAL CREDIBILITY:
Optionally include a terminal window or reference that shows:
- A CLI session
- Layers or systems being "loaded"
- Reinforces that this is a real system with architecture, not just a visual concept

OVERALL IMPRESSION:
The interface should immediately communicate:
- Multi-agent orchestration
- Human + AI collaboration
- Infrastructure-level power
- A place where serious work happens all day

Avoid marketing fluff. This should feel like an internal OS used by builders, operators, and founders.
```
