🤖 REDDIT (u/blackroados) - Post to r/SideProject

Title: I built Context Bridge - AI context management for developers

Text:

Hey r/SideProject!

I've been working on Context Bridge for the past few months. It's an AI-powered context management tool that helps developers work more efficiently.

The problem: Every time you switch between AI conversations, you lose context. Copy-pasting code and docs gets old fast.

The solution: Context Bridge remembers everything. Your codebase, your docs, your previous conversations.

Tech stack: Chrome extension (Manifest V3), Node.js backend, TypeScript

Current status: Live! You can try it at blackroad.io

Would love feedback from other developers. What features would make this more useful for you?

Thanks for checking it out! 🚀
