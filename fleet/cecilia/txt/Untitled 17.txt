🤖 Canonical Agent Roles (by Phase)

These never change.
Only configuration does.

⸻

Phase 1 — Intake (Sense & Triage)

phase_1_agents:
  - name: signal_ingestor
    role: collect requests, events, anomalies
  - name: classifier
    role: tag domain, risk, urgency
  - name: deduplicator
    role: merge similar intents
  - name: router
    role: assign workflow_id + window

Inputs: emails, tickets, metrics, humans, APIs
Outputs: normalized workflow intent

⸻

Phase 2 — Planning (Decide & Approve)

phase_2_agents:
  - name: planner
    role: generate execution plan
  - name: policy_guard
    role: check compliance + constraints
  - name: approver
    role: request / validate human approval
  - name: estimator
    role: cost, time, risk estimation

Outputs: approved plan or rejection
Nothing executes without passing here.

⸻

Phase 3 — Execution (Act)

phase_3_agents:
  - name: executor
    role: perform actions (code, infra, ops)
  - name: integrator
    role: call external systems
  - name: verifier
    role: validate results vs plan

This is the only phase allowed to change reality.

⸻

Phase 4 — Maintenance (Observe & Improve)

phase_4_agents:
  - name: monitor
    role: watch metrics + drift
  - name: auditor
    role: immutable logs + evidence
  - name: optimizer
    role: suggest improvements
  - name: archivist
    role: close workflow + retain records


⸻

🧠 Universal Guarantees (important)
	•	Agents never skip phases
	•	Humans can enter only at Phase 2
	•	Rollbacks are Phase 3 → Phase 2 loops
	•	Audits always land in Phase 4

This is why it’s safe.

3️⃣ br Command (minimal shell version)

cat << 'EOF' > ~/.blackroad/bin/br
#!/usr/bin/env bash

WF="$2"
WF_FILE="$HOME/.blackroad/workflows/$WF.yaml"

if [[ "$1" != "run" || ! -f "$WF_FILE" ]]; then
  echo "Usage: br run <WORKFLOW_ID>"
  exit 1
fi

SESSION="br-$WF"

tmux new-session -d -s "$SESSION" -n "$WF"

tmux split-window -h
tmux split-window -v
tmux select-pane -L
tmux split-window -v

tmux select-pane -t 0 -T "Phase 1 · Intake"
tmux select-pane -t 1 -T "Phase 2 · Planning"
tmux select-pane -t 2 -T "Phase 3 · Execution"
tmux select-pane -t 3 -T "Phase 4 · Maintenance"

tmux send-keys -t 0 "echo '[$WF] Phase 1: Intake'" C-m
tmux send-keys -t 1 "echo '[$WF] Phase 2: Planning'" C-m
tmux send-keys -t 2 "echo '[$WF] Phase 3: Execution'" C-m
tmux send-keys -t 3 "echo '[$WF] Phase 4: Maintenance'" C-m

tmux attach -t "$SESSION"
EOF
