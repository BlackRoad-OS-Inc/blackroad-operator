╔═══════════════════════════════════════════════════════════════════════════╗
║                            🚀 QUICK START                                 ║
╚═══════════════════════════════════════════════════════════════════════════╝

  roadpad                  → Start with Copilot prompt
  roadpad file.txt         → Open file in editor mode
  roadpad notes.road       → Open .road file

╔═══════════════════════════════════════════════════════════════════════════╗
║                          ⌨️  KEYBINDINGS                                  ║
╚═══════════════════════════════════════════════════════════════════════════╝

┌─────────────────────────────────────────────────────────────────────────┐
│ MODES                                                                   │
├─────────────────────────────────────────────────────────────────────────┤
│  Ctrl+P         Toggle prompt ↔ editor mode                            │
│  :              Enter command mode (vim-style)                          │
│  Esc            Exit command/prompt mode                                │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ EDITING                                                                 │
├─────────────────────────────────────────────────────────────────────────┤
│  Arrow keys     Navigate                                                │
│  Enter          New line                                                │
│  Backspace      Delete char before cursor                               │
│  Delete         Delete char at cursor                                   │
│  Tab            Insert 4 spaces                                         │
│  Home           Move to line start                                      │
│  End            Move to line end                                        │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ FILE OPERATIONS                                                         │
├─────────────────────────────────────────────────────────────────────────┤
│  Ctrl+S         Save file                                               │
│  Ctrl+O         Open file dialog                                        │
│  Ctrl+Q         Quit                                                    │
│  :w [file]      Save (vim-style)                                        │
│  :q             Quit (warns if unsaved)                                 │
│  :q!            Quit without saving                                     │
│  :wq            Save and quit                                           │
│  :e file        Open file                                               │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ COPILOT                                                                 │
├─────────────────────────────────────────────────────────────────────────┤
│  Shift+Tab      Cycle accept mode (manual → on save → always)          │
│  > [prompt]     Send query to Copilot (in prompt mode)                 │
└─────────────────────────────────────────────────────────────────────────┘

╔═══════════════════════════════════════════════════════════════════════════╗
║                            🎯 MODES                                       ║
╚═══════════════════════════════════════════════════════════════════════════╝

  PROMPT MODE (Default)
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Type at the > prompt and press Enter to send to Copilot.
  Responses appear in the buffer below.

  Example:
    >  what is quantum computing

  EDITOR MODE (Ctrl+P)
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Standard text editing. Type normally, use arrow keys to navigate.
  Save with Ctrl+S, quit with Ctrl+Q.

  COMMAND MODE (:)
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Vim-style commands for file operations.
  Type : to enter, Esc to exit.

╔═══════════════════════════════════════════════════════════════════════════╗
║                         ⚙️  ACCEPT MODES                                  ║
╚═══════════════════════════════════════════════════════════════════════════╝

  Cycle with Shift+Tab:

  1. manual      → Edits require explicit accept (show diff)
  2. on save     → Edits apply when you save (Ctrl+S)
  3. always      → Edits apply immediately

  Current mode shown in status bar:
    ⏵⏵ accept edits [MODE] (shift+tab to cycle)

  .md      Markdown files (stored as plain text)

╔═══════════════════════════════════════════════════════════════════════════╗
║                         💡 USAGE EXAMPLES                                 ║
╚═══════════════════════════════════════════════════════════════════════════╝

  Quick Query
  ───────────────────────────────────────────────────────────────────────
  $ roadpad
  >  what is the capital of France
  [Press Enter]
  [Response appears]

  Edit with Copilot Help
  ───────────────────────────────────────────────────────────────────────
  $ roadpad script.py
  [Edit your code]
  [Press Ctrl+P]
  >  how do I optimize this code
  [Press Enter, see response]
  [Press Ctrl+P to return to editing]
  [Apply changes]
  [Press Ctrl+S to save]

  Session Notes
  ───────────────────────────────────────────────────────────────────────
  $ roadpad notes.road
  [Take notes]
  [Press Ctrl+P for quick queries]
  [Responses inline with notes]
  [Press Ctrl+S to save everything]

╔═══════════════════════════════════════════════════════════════════════════╗
║                         🎨 DESIGN PRINCIPLES                              ║
╚═══════════════════════════════════════════════════════════════════════════╝

  • Plain text only      → No formatting stored
  • Deterministic        → Same input = same output
  • Diff-safe            → Can pipe, compare, version control
  • No AI branding       → Clean Lucidia interface
  • Copilot bridge       → Subprocess, no API keys needed
