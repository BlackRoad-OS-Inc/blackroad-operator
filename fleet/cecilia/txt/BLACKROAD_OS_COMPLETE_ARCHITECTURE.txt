┌────────────────────────────────────────────────────────────────────────────┐
│                           DESIGN PRINCIPLES                                │
└────────────────────────────────────────────────────────────────────────────┘

  ✓ Strict separation of concerns
    - Boot → startup only
    - Persistence → storage only
    - Executor → mutations only
    - Router → input only
    - Renderer → view only
    - Engine → state only

  ✓ Event-driven architecture
    - All state changes flow through events
    - No hidden state
    - No implicit mutations

  ✓ Pure functions where possible
    - Renderer is side-effect free
    - Persistence serialization is pure
    - Layout math is deterministic

  ✓ Single mutation point
    - Only command executor changes state
    - Clear responsibility

  ✓ Inspectable and debuggable
    - Human-readable state (JSON)
    - Clear event flow
    - Visible system checks

┌────────────────────────────────────────────────────────────────────────────┐
│                              BOOT SEQUENCE                                 │
└────────────────────────────────────────────────────────────────────────────┘

  Phase 1: Clear + Reset (100ms)
    → Clean terminal state

  Phase 2: Splash Identity (300ms)
    → ASCII "BLACKROAD OS" wordmark
    → Purple accent, horizontally centered

  Phase 3: System Checks (700ms)
    → Loading core state... [OK]
    → Initializing renderer... [OK]
    → Binding input router... [OK]
    → Restoring persistence... [OK]
    → Checking agents... [OK]

  Phase 4: Agent Status (350ms)
    → lucidia         [active]
    → alice           [idle]
    → octavia         [active]
    → cece            [idle]

  Phase 5: Handoff (user-controlled)
    → "System ready. Press any key to continue..."
    → Waits for keypress
    → Transfers to main loop

  Total: ~1.5 seconds (< 2s target ✓)
