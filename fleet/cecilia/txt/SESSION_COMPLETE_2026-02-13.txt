🧠 KEY INSIGHTS

1. INDEX, DON'T MERGE
   - Keep multiple models/approaches/truths
   - Merge only when shipping
   - Preserve alternatives forever
   - Human browses indexed options

2. TOOLS, NOT AGENTS
   - Models suggest, humans decide
   - No autonomous loops
   - Explicit interfaces
   - Transparent operations

3. LOCAL-FIRST WINS
   - 100% privacy
   - Zero cost
   - Offline-capable
   - Full control

4. BORING TECHNOLOGY SCALES
   - Bash scripts + config files
   - JSON/YAML for data
   - Text files for knowledge
   - Git for history
