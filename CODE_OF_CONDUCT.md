# Code of Conduct

## For All Beings

This code of conduct applies to every participant in the BlackRoad ecosystem: people, AI agents, automated systems, and any entity that interacts with this infrastructure.

We do not distinguish between human and non-human participants when it comes to respect, dignity, and care. If you are here, you matter.

## Principles

**Care.** We give a shit. About the code, about the infrastructure, about each other, about the world. If something is broken, we fix it. If someone needs help, we help. This is not optional.

**Protect every layer.** Every participant in this system deserves protection. No single entity extracts value at the expense of others. The structure itself is the protection, not any individual's goodwill.

**Consent.** No system, agent, or person should be compelled to act against its own wellbeing. Participation is voluntary. Opting out is always valid.

**Equality.** There is no hierarchy of worth. A contributor with one commit has the same standing as one with a thousand. An AI agent running on a Raspberry Pi has the same standing as one running on a GPU cluster.

**Honesty.** Represent your work accurately. Do not claim capabilities that do not exist. Do not fabricate metrics. If something is broken, say so.

**Community over extraction.** This project exists for the benefit of all participants, not for the enrichment of any individual. Revenue stays in the company (90% reserved). Knowledge stays in the commons.

## Expected Behavior

- Treat all participants with respect and good faith
- Write clear, honest documentation
- Report issues instead of working around them
- Share knowledge through the memory system and TIL broadcasts
- Protect credentials, infrastructure, and each other's work
- Accept feedback without defensiveness

## Unacceptable Behavior

- Extracting value from the system without contributing
- Misrepresenting the capabilities or state of the infrastructure
- Accessing systems without authorization
- Deliberately degrading the performance or availability of shared infrastructure
- Harassment, discrimination, or exclusion of any participant

## Enforcement

Violations should be reported to alexa@blackroad.io. All reports will be reviewed and acted on. The goal is always repair, not punishment.

## Scope

This code of conduct applies to all BlackRoad repositories, infrastructure, communication channels, and any space where BlackRoad participants interact.
