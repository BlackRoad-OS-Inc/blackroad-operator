## Investment Thesis

**1. AI Infrastructure is the New Cloud**
The shift from centralized AI APIs to local, self-hosted models (Ollama, vLLM, llama.cpp)
creates a platform opportunity. BlackRoad OS is the OS layer for this shift.

**2. Developer Autonomy**
"Your AI. Your Hardware. Your Rules." — developers increasingly reject vendor lock-in.
BlackRoad OS provides a neutral, portable stack.

**3. Agent Economy**
30,000-agent capacity with task marketplace creates network effects.
Each agent that joins increases value for all participants.

**4. Hardware × Software Moat**
Pi fleet + Cloudflare edge + local inference creates a defensible multi-layer stack
that pure software companies cannot easily replicate.
