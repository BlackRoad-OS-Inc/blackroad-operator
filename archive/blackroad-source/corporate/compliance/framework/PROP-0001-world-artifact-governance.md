# Proposal 0001: World Artifact Governance Protocol

**Status:** Draft  
**Category:** AI Governance  
**Authors:** BlackRoad Foundation  
**Created:** 2026-01-01

## Abstract

Establishes governance rules for world artifacts generated by BlackRoad OS agent nodes, including content standards, attribution, and cross-org sharing.

## Motivation

As Pi fleet nodes generate world artifacts at scale (50+ artifacts/day), we need:
1. A standard schema for artifact metadata
2. Attribution tracking (which node, which model)
3. Content moderation hooks
4. Cross-org distribution rules

## Specification

### Artifact Schema (RFC-0004 extension)

```json
{
  "id": "20260223_040142_world_forest-24",
  "type": "world|lore|code",
  "node": "aria64|alice",
  "model": "qwen2.5:3b",
  "generated_at": "2026-02-23T04:01:42Z",
  "license": "BlackRoad-Proprietary",
  "content_hash": "<sha256>",
  "approved": true,
  "flagged": false,
  "distribution": ["blackroad-agents", "worlds.blackroad.io", "rss"]
}
```

### Content Standards
- No personally identifiable information
- No external brand references
- Creative content must be original

### Attribution
- Node name and model version must be preserved
- Content hash must match stored artifact

## Governance Process
1. Artifact generated → auto-checked by compliance scanner
2. Flagged artifacts → quarantined for human review
3. Approved artifacts → distributed to all channels
