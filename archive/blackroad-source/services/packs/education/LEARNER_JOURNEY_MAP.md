# Learner Journey Map

| Phase      | Description | Supporting Agents |
|------------|-------------|-------------------|
| Discover   | Learners explore offerings and outcomes. | Syllabus Architect (for clear value propositions) |
| Enroll     | Learners commit to a pathway and schedule. | Student Success Bot (eligibility nudges) |
| Onboard    | Learners get set up with accounts and expectations. | Student Success Bot (onboarding nudges) |
| Learn      | Core instruction and practice. | Syllabus Architect (module alignment) |
| Assess     | Checkpoints, quizzes, and projects. | Assessment Designer (question banks & rubrics) |
| Improve    | Iteration based on feedback and outcomes. | All agents via `continuous_improvement` workflow |
| Alumni     | Post-course engagement and referral loops. | Student Success Bot (alumni engagement prompts) |
