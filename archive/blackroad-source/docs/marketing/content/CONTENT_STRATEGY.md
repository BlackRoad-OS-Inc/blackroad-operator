# BlackRoad Content Strategy

## Brand Voice
- **Tone:** Confident, technical, human
- **Style:** Direct > verbose. Code > prose where applicable.
- **Personality:** We're building the OS for autonomous AI. Own it.

## Content Types

### Technical Content
- Architecture docs in `blackroad-infra/`
- API reference auto-generated from OpenAPI specs
- Agent guides in `blackroad-agents/`

### Marketing Content
- Landing pages: Cloudflare Pages workers
- Blog: hosted at `blog.blackroad.io`
- Social: Twitter/X, LinkedIn, GitHub

## Asset Storage
- Design tokens: `BlackRoad-Media/brand-kit/tokens/`
- Logo files: `BlackRoad-Media/brand-kit/logos/`
- Screenshots/demos: Cloudflare R2 `blackroad-assets`

## SEO Strategy
- Primary keywords: "BlackRoad OS", "AI agent platform", "tokenless AI gateway"
- Structured data on all pages
- OpenGraph tags with brand gradient thumbnail
