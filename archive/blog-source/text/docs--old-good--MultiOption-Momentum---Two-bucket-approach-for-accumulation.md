MultiOption® Momentum

MultiOption Momentum is an investment-only variable annuity (IOVA), which 
gives clients the opportunity to use both variable investments and indexed 
account options to help invest for the future.
It also helps manage wealth to achieve long-term retirement goals. With one 
bucket that allows you to allocate for more growth potential, and the other 
bucket for more safety, MultiOption Momentum can be customized to meet an 
individual’s investment risk comfort level.
•	The option to allocate up to 100% 
into variable subaccounts
•	75+ variable investment options 
available
•	Investment changes available 
without triggering a taxable event
•	0.90% M&E and Admin charges 
(0.80% if net purchase payments $1 
million or greater)¹
•	Daily value shown
•	No M&E or Admin charges when 
allocating to indexed options
•	The interest credited will never be 
less than zero, which acts as a safety 
net during market downturns
•	The option to allocate up to 100% 
into indexed options
•	Diverse lineup of Indexed Account 
offerings:
	- S&P 500® Index
	- Barclays All Caps Trailblazer 5 Index
	- SG Climate Prepared Index
•	1-Year Point-to-Point growth. Interest 
may be credited at the end of each 
contract year based on how that 
account’s index performed
