## LinkedIn Best Practices

10 Best Practices For LinkedIn |  |  |  |  |  |  |  |  |  |  | 
Be consistent. | When building an audience for your LinkedIn profile, you’ll need to establish a regular presence to keep them engaged. Whether that consistency is 1-2 times a week or every day, committing to deliver your content regularly is the first step in keeping the attention of your audience! |  |  |  |  |  |  |  |  |  | 
Know your audience. | Posting meaningful content on a regular basis is a great start, but you’ll need to specify your target audience if you want your content to flourish! What does your audience like? What’s their age group? What similarities do you share with your audience? |  |  |  |  |  |  |  |  |  | 
Be celebratory. | Pat yourself on the back! You’re progressing every day that you put your best foot forward. No win is too small to celebrate. Share your life, career, or educational achievements with your audience. You may be shocked by the amount of support you receive! |  |  |  |  |  |  |  |  |  | 
Visualize your message. | When drafting your next LinkedIn post, ask yourself: Is this formatting visually appealing? Consider using smaller paragraphs, bullet points, and use a hook to keep your readers engaged in your posts! |  |  |  |  |  |  |  |  |  | 
Be social. | What would social media be if no one chose to interact with one another? Don’t forget that your profile isn’t just for others to interact with you. Share a comment or two, join a live session, or show some support to fellow peers, colleagues, or mutuals! |  |  |  |  |  |  |  |  |  | 
Prioritize personability. | Don’t forget… Your audience isn’t a bunch of robots! Make it your mission to bring life to your posts by sharing personal experiences, showcasing your personality, and adding a little humor here and there ;) |  |  |  |  |  |  |  |  |  | 
Create valuable content. | If your’re wondering how to create valuable content, it’s all about your purpose and delivery. Be strategic about getting your point across. Utilize your resources to create good-quality graphics/ videos.  |  |  |  |  |  |  |  |  |  | 
Be knowledgeable. | Adding photos and videos to your posts is a great way to increase content visibility. Create simplistic educational graphics, informative videos (shorter than 30 seconds when possible), and include photos from time-to-time to enhance your audience’s content experience. |  |  |  |  |  |  |  |  |  | 
Focus on your journey. | It's easy to get sidetracked when you're paying more attention to the success of others rather than your own. Choose to enjoy your journey by focusing on your wins, areas of improvement, and your goals! |  |  |  |  |  |  |  |  |  | 
Be open. | When crafting your LinkedIn content, be open to new directions, communities, and discussions. You don’t want to limit your potential by passing up what could be opportunities for growth and awareness! |  |  |  |  |  |  |  |  |  |
