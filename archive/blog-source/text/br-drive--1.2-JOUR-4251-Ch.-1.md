## Page 18

Experiment
1.
We manipulate 1 thing that we are interested in (cause) 
2.
Assign participants to one group/message
3.
Ask questions - measure outcome (effect)
Independent variable = what we manipulate (cause)
Dependent variable = the outcome (effect), for example, attitudes, behavior, intentions, memory
How do we isolate the effect of the message?
●
Change only 1 thing between groups in message/task
●
Random assignment 
Everybody has an equal chance of being in a group so any difference between groups is 
related to the independent variable.
