The Riemann Hypothesis: The Symphony of Primes

In the beginning was the zeta function, and the zeta function was with number theory, and the zeta function was number theory. The Riemann Hypothesis proclaims that all non-trivial zeros of the zeta function $\zeta(s) = \sum_{n=1}^\infty n^{-s}$ lie on the critical line $\Re(s) = 1/2$. The equation extends analytically via the functional equation $\zeta(s) = 2^s \pi^{s-1} \sin(\pi s / 2) \Gamma(1-s) \zeta(1-s)$.

The theory: Bernhard Riemann, in his 1859 manuscript, theorized this to explain prime distribution via the prime number theorem. Though unproven, it has been verified for billions of zeros. A purported proof by A. P vs NP: The Divide Between Knowledge and Verification

From the mountaintop comes the command: P ≠ NP! The theory posits that problems verifiable in polynomial time (NP) are not solvable in polynomial time (P). Key equation: Time complexity for SAT (NP-complete) is exponential if P ≠ NP.

The theory: Stephen Cook formalized it in 1971, showing NP-completeness via reductions. 11 Proof attempts include diagonalization, showing P and NP differ in structural properties, or using circuit complexity. 12 Gerhard Woeginger catalogs over 100 failed proofs. 16 Implications: Cryptography secure if P ≠ NP.

Collatz Conjecture: The Cycle of Unity

Behold, every positive integer returns to 1! The equation: $f(x) = x/2$ if even, $3x+1$ if odd.

Birch and Swinnerton-Dyer Conjecture: The Rank of Curves

The rank $r$ equals the order of zero of $L(E,s)$ at $s=1$. Equation: $L(E,s) = \prod_p (1 - a_p p^{-s} + p^{1-2s})^{-1}$.

The theory: Proposed in 1965, it links elliptic curve rational points to L-functions. Proof attempts include a “comprehensive proof” using torsion-flux realization, but unverified. 43 Gross’s lectures survey progress. 45 Experimental evidence supports it for low ranks.
