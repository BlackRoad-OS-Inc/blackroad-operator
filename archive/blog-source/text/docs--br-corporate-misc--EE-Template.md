Comparable Market Analysis (CMA): | The CMA evaluates homes in an area that have comparable characteristics to the subject property.  I typically research homes by school district or area, and look at the number of bedrooms and bathrooms and countless other characteristics that determine a home's value, such as a finished lower level or an attached garage.  My analysis includes homes that are Active, Contingent, Under Agreement, and -- most importantly -- ones that have Sold  to determine the nature of the competitive market in the area and the types of homes that are selling.  Of all our methods of analysis, the CMA carries the most weight in determining the correct listing price. |  |  |  |  |  |  |  |  |  |  |  |  |  | 
Neighborhood Appreciation: | This method assesses multiple past sales in the subject property's subdivision, adjoining streets, or in a several-block radius to determine the average annual appreciation or depreciation in property values in the area.  Appreciation or depreciation is defined as a change in value over time, and can be due to a number of factors such as new roadways, new access to shopping centers, or a change in the average price of homes being built in the area.  To arrive at an annual percentage increase or decrease, I look at several homes that have sold at least twice in the past ten years.  I compare the two sale prices and sale dates to arrive at an estimate of the change in each home's market value.  I then apply the average change in value for all the homes sampled to estimate a change in value for the subject property since the date it was purchased. |  |  |  |  |  |  |  |  |  |  |  |  |  | 
Technical Analysis: | It is a common mistake for home owners or prospective buyers to assume that the assessed value of a home reflects its true value or the price at which it would sell.  Assessed values (sometimes referred to as Market Values) are used primarily for determining property taxes and are typically outdated.  For example, the assessed values for homes in Allegheny County are from assessments conducted in 2001, and may not be reflective of current home values.  Even if outdated, assessed values can be useful in calculating the current value of a home.  Since assessments are typically conducted for all the homes in a given area during the same year, the assessed value for one home can be used for comparison to another home.  My research methodology identifies homes that sold within an area within the past year and compares the prices at which they sold to their assessed values.  For each home, we calculate a percentage ratio of the sold price to the assessed value.  Then I apply the high, low and average percentage ratios from our sample of homes to the subject property's current assessed value to calculate a listing price and a price range. |  |  |  |  |  |  |  |  |  |  |  |  |  |
