Fixed Indexed Annuity:

If the index being tracked is positive from a point in time to a point in time, you get a +. A “ + “ means a positive value, and the crediting methods explained below determines how much of a “ + “ you get. If the market is negative, you simply get a “ 0 “ as a value for the point in time to the point in time. You can’t lose money hypothetically, but there’s inflation etc. for now, we just care about if it’s positive you get + if its negative you get 0.

With this, there is a fixed interest account attached. You are able to move funds from the index being tracked and safeguard them in the fixed account every anniversary date of the contract. The same is said for moving funds from the fixed account to the account in which the index is being tracked. There are crediting methods, again, described below, and these you can have different allocations amongst them.

Crediting Methods:

Participation Rate:

Simply the amount you participate in the index gain being tracked if the index is positive from a point in time to a point in time, for Securian it is the anniversary date of the contract

Cap Rate:

Easier to understand its effect. If you “participate” in 100% of the index gains, great, you get it all. However, if you have a 100% participation rate with say a 5% cap rate, imagine the following scenario to help:

You invest $100,000 into a S&P 500 Index fund, which is initially the price of $50,000. The index then moves to $200,000 (easier for numbers). If you had a 100% participation rate then you would get $400,000. ($50,000 x 4 = $200,000; $100,000 x 4 = $400,000) However, that’s a 400% return. Instead, what a 5% cap does is limit Karen to 5% of the upside. KAREN THE ANNUITY CLIENT WILL RECEIVE THE FULL PARTICIPATION AMOUNT AS LONG AS THAT NUMBER IS LESS THAN THE CAP. Sadly then, Karen only gets $5,000. Now, her account is adjusted to $105,000, and the game begins again. But wait, there’s more. There are reset rates.

Next is spreads.

Spreads:

100% participation rate, 10% cap, 5% spread? Well that 10,000 from the scenario above for the cap. But instead they take off 5% off that value at the end.

Performance Triggers:

Say you have a 5% performance trigger, what that means is if the index performance hits x for a value, say if index performance is greater than 10%, you get 5%. So, $50,000 goes to $100,000, that is 400% performance which definitely triggers this thing, so you will get 5% of that 400% gain.

Inverse Performance Trigger

The same is true for inverse triggers. Market goes down from $200,000 to $50,000, this triggers it as well. You will receive a bigger gain because someone said so and it pays instead, 15%.
