## Page 1

Context
This dataset was obtained by myself from the top crypto Telegram groups using the Telegram
API and the Telethon Python module. More details on Telethon can be found here:
https://docs.telethon.dev/en/latest/
The dataset is in JSON  format. This particular JSON  is easy to read and load into a Pandas
data frame. Refer to my notebook here: https://www.kaggle.com/aagghh/trends-in-crypto-
space-telegram-analysis
The size of the dataset is 2.8GB
Content
This dataset contains records of approximately 3+ million messages in the official top crypto
exchanges Telegram groups from various users. Also, it contains data such as dates, number
of views, shares, and many more.
