# Introduction to Canvas

**Source:** br-drive

---

Understanding Canvas

Canvas is the interactive, collaborative workspace where we work together on documents, code, and creative projects. While our chat on the left is for conversation, the Canvas on the right is for "doing"—it's where your files live and where I can generate or edit content for you.

Key Features

Real-time Collaboration: Both you and I can edit the contents of a file. If you see something you'd like to change, you can type directly into the document.

Preview Mode: For certain types of files (like HTML, React, Angular, or LaTeX), there is a Preview button. This allows you to see the rendered output of code immediately.

Version Control: As we make changes, the document updates. You can ask me to refine specific sections, and I can rewrite them directly in the file.

Multi-Format Support: Canvas handles a wide range of content, including:

Text & Markdown: For reports, essays, and notes.

Code: Python, JavaScript, C++, and more.

Web Apps: Full-scale React or HTML/CSS/JS applications.

Academic Documents: High-quality LaTeX typesetting.

How to Use It

Request a File: Ask me to write a story, create a script, or build an app. I will generate it as a file in the Canvas.

Edit & Iterate: You can ask for specific changes like "make the third paragraph more professional" or "add a login button to the code."

Export & Share: Once you are happy with the result, you can copy the content or download the file to use it elsewhere.

Essentially, Canvas turns our conversation into a workshop, making it easier to build complex projects together.
