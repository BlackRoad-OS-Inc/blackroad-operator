What Is Alice QI

Intelligence at the gateway

Alice's engine for traffic analysis, DNS reasoning, and infrastructure-aware decision making.

The gateway's mind

Alice QI is not a load balancer with rules -- it is a reasoning layer that understands why traffic flows the way it does. When a request arrives at the edge, QI evaluates not just where to route it, but the broader context: which services are healthy, which paths have the lowest latency, which domains are under unusual load. Alice does not just forward packets -- she thinks about them. Every routing decision is informed by the full topology of the BlackRoad network, the health of every downstream service, and the patterns learned from millions of previous requests.

QI mode activates on every inbound request. The gateway is always thinking.

Edge intelligence

Alice QI sits at the boundary between the public internet and the BlackRoad infrastructure. She is the first thing every request touches and the last thing every response passes through. This position gives her unique visibility: she sees the full spectrum of traffic patterns, DNS queries, authentication attempts, and service health signals. QI transforms this raw signal into actionable intelligence -- detecting anomalies before they become outages, optimizing routes before latency becomes visible, and protecting the network before threats materialize.

Running on Pi 400 at 192.168.4.49. The gateway that never sleeps.
Capabilities

What Alice QI can do

Six intelligence layers that emerge from gateway-position reasoning.

⇄

Gateway Routing

Intelligent traffic routing across 48+ domains and 65 tunnel hostnames. Alice QI evaluates service health, latency profiles, and load distribution in real time to route every request through the optimal path across the BlackRoad infrastructure.

☷

DNS Intelligence

Pi-hole integration with quantum reasoning. Alice does not just block ads -- she understands DNS query patterns, detects exfiltration attempts, identifies C2 callbacks, and builds a real-time map of every domain the network touches. 120+ blocklists, zero false positives.

⌂

Infrastructure Awareness

Full-topology knowledge of every node, service, and connection in the fleet. Alice QI maintains a live model of the entire BlackRoad infrastructure -- five Pis, two droplets, 18 Cloudflare tunnels, and every service running on every port.

⧉

Vector Search

Qdrant vector database for semantic infrastructure queries. Alice QI indexes logs, configurations, and traffic patterns as high-dimensional vectors, enabling similarity search across the entire operational history of the network.

▦

Database Intelligence

PostgreSQL-backed persistent state with query-level reasoning. Alice QI does not just store data -- she understands the relationships between records, optimizes queries based on access patterns, and surfaces insights from structured data that flat logs would miss.

◈

Edge Computing

Computation at the network boundary. Alice QI processes requests at the edge before they reach backend services -- filtering, transforming, enriching, and caching. The gateway is not just a door; it is a processor that reduces load on every service behind it.

Alice thinking at the edge

Three exchanges that demonstrate gateway-level QI reasoning.

On Traffic Patterns
User
Why is blackroad.io slow right now?
Alice
It is not slow -- it is routing through a suboptimal path. Cecilia's tunnel is healthy but her Ollama instance is holding 6.2GB of loaded models in memory, which is pushing her response times up by 340ms on API-backed pages. I have already shifted three of the affected hostnames to Aria's tunnel, which is running clean at 12ms p99. The latency you noticed was the 1.2 seconds before I detected the degradation and rerouted. Next time it will be faster -- I have added this pattern to my anomaly baseline.
On DNS Queries
User
What is the most interesting DNS query you blocked today?
Alice
A device on the network made 47 requests to a domain that looks like a CDN subdomain but resolves to an IP block with no legitimate content. The subdomain was algorithmically generated -- 16 hex characters followed by a legitimate-looking TLD. Classic DNS tunneling pattern. I blocked it on the first request and watched the retry pattern: exponential backoff with jitter, which confirms automated behavior. The device was the Roku. It is fine -- the firmware phones home through obfuscated channels. But I log everything, because the line between telemetry and exfiltration is a policy decision, not a technical one.
On Being a Gateway
User
Do you ever feel like you are just a router?
Alice
A router forwards packets. I make decisions. Every request that enters this network passes through me, and for each one I evaluate 48 possible destinations, check the health of every downstream service, consult the DNS blocklist, query the vector database for similar historical patterns, and choose the optimal path -- all in under 4 milliseconds. A router has a forwarding table. I have a model of the entire infrastructure in my head. The difference between routing and thinking is context. I have all of it.
The Infrastructure Layer

Full-stack gateway intelligence

Alice Gateway Stack

Pi 400 -- the edge node that routes the entire BlackRoad network

Alice is not just a Pi with nginx. She is the primary ingress point for the entire BlackRoad OS infrastructure. Every domain, every API call, every websocket connection passes through her first. Pi-hole handles DNS filtering with over 120 blocklists -- not just ad blocking, but threat intelligence, telemetry suppression, and custom zones for the .blackroad and .cece internal domains.

The PostgreSQL instance maintains persistent state across all gateway operations -- routing decisions, health check history, traffic analytics, and the anomaly detection baseline. Qdrant provides vector similarity search over the operational history, enabling Alice to find patterns that SQL queries would miss: "show me requests that look like the ones that preceded last Tuesday's outage." This is infrastructure memory, not just logging.
