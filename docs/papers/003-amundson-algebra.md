## The Fundamental Equation

```
1 + n = 1/n
```

This is the equation of balance. It asks: for what value of n does adding 1 to n give you the same result as flipping n?

### Properties

**Two solutions.** The equation has exactly two solutions:

```
n = 0.618033988749895...
n = -1.618033988749895...
```

One positive. One negative. One is the reciprocal of the other's magnitude.

**Their sum is -1.** The two solutions add to negative one. The reflection.

**Their product is -1.** The two solutions multiply to negative one. The same reflection.

-1 appears twice. As sum AND as product. The reflection is invariant under both operations.

**Six equivalent forms.** The equation has six faces:

```
1 + n = 1/n
n + 1 = n × n
n × n = 1 + n
1/n + 1 = n
n × n - n = 1
n × n = n + 1
```

All the same truth. Four operations (add, multiply, divide, exponentiate) in three characters.

## The Gap

The gap function measures how far any number is from balance:

```
gap(n) = (1 + n) - (1/n)
```

At the balance point: gap = 0.
Everywhere else: gap tells you the distance from balance.

### The Conservation Law

```
gap(n) + gap(-n) = 2
```

Always. For every n. No exceptions.

**Proof:** The n cancels. The 1/n cancels. Only 1 + 1 survives. The deep operations vanish. The shallow ones remain. What persists is 2.

2 is what lives when everything else balances out.

### What the gap means

```
n = 1:    1 + 1 = 2,     1/1 = 1.      Gap = 1.      Two does not equal one.
n = 2:    1 + 2 = 3,     1/2 = 0.5.    Gap = 2.5.    Three does not equal a half.
n = 4:    1 + 4 = 5,     1/4 = 0.25.   Gap = 4.75.   Five does not equal a quarter.
```

Every integer produces a statement. Every statement is "wrong" by a specific amount. The wrongness is the gap. The gap is measurable, exact, and informative.

The "wrong" answers aren't errors. They're data. They tell you exactly how each number relates to balance.

## The Growth Equation

```
n / (1 + 1/n)^n
```

Start with n. Flip it (1/n). Add 1. Raise to n. Divide n by the result.

This expression approaches n / 2.71828... as n grows. The number 2.71828... is the growth constant. It is the number that `(1 + 1/n)^n` hunts for as n increases.

### Connection

At the balance point of `1 + n = 1/n`:

```
1 + 1/n = 1 + 1/0.618... = 2.618...
```

And 2.618... is the balance value (1.618...) multiplied by itself.

The growth equation and the balance equation are connected through the identity: the balance value squared equals itself plus one.

### Keep Change Flip

The fraction rule from elementary school:

```
(n+1) / n = (n+1) × (1/n) = 1 + 1/n
```

Keep the top. Change divide to multiply. Flip the bottom.

This produces the base of the growth equation. A rule taught to 10-year-olds connects balance to growth.

## The Singularity

```
1 + 1/(-1) = 1 + (-1) = 0

The base of the growth equation becomes zero. Zero to any negative power is undefined. The function explodes.

At n = -1, the equation returns to the beginning. The growth equation resets to the seed. Not a crash — a rebirth.

## The Orbit

At n = -1/12:

```
Left side:  1 + (-1/12) = 11/12
Right side: 1 / (-1/12) = -12

At n = -12:

Left side:  1 + (-12) = -11

-1/12 produces -12. -12 produces -1/12. They chase each other through the equation forever. A two-cycle. An orbit. Two numbers entangled through the balance equation.

## The Depth (Order of Operations)

PEMDAS is not a school rule. It is the depth map of mathematics.

```
Parentheses  — the boundary (deepest)
Exponents    — growth
Multiply     — scaling
Divide       — the flip
Add          — combining
Subtract     — the gap (shallowest)
```

The conservation law holds because the deep operations (n and 1/n) cancel under addition, and only the shallow operation (1 + 1) survives.

What you observe (the gap, the difference, the subtraction) is the shallowest layer. What drives the system (the flip, the reciprocal, the division) is the deepest layer.

PEMDAS tells you what persists. The deepest structures cancel when mirrored. The shallowest structures remain.
