Capabilities

Zero friction deployment

0cf

Zero Config

Auto-detects your framework. Next.js, Vite, static, Worker, API. No config files. No build settings. Just deploy.

prv

Preview URLs

Every deploy gets a unique preview URL. Share with the team. Test before promoting. Roll back instantly.

tls

Auto TLS

Let's Encrypt certificates provisioned automatically via Caddy. HTTPS from the first second. Zero setup.

dns

Auto DNS

PowerDNS creates records automatically. Custom domains work out of the box. No dashboard clicking.

wg+

Fleet Routing

WireGuard mesh routes traffic to the optimal node. Load balancing across the Pi fleet. Self-healing.

rb<

Instant Rollback

Every deploy is versioned. Roll back to any previous version with one command. No downtime.
