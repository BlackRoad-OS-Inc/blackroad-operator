Features

Sync without compromise

🔒

End-to-end encrypted

Files encrypted before they leave the device. Decrypted only on the destination. Not even the relay node can read them.

🔄

Conflict resolution

Edit the same file on two devices? RoadSync detects conflicts and keeps both versions. You choose which wins.

📦

Version history

Every change creates a version. Roll back to any point. Incremental deltas keep storage efficient.

⚡

Instant sync

File change detected, synced in milliseconds. inotify/FSEvents watchers. No polling. No delays.

🔍

Selective sync

Choose which folders sync to which devices. Not everything needs to be everywhere. Fine-grained control.

🌐

Self-hosted

MinIO for object storage. WireGuard for transit. Your hardware, your files, your rules. No cloud required.
