What Is RoadID

Sovereign identity for the AI age

Every entity in the BlackRoad ecosystem has a verifiable, persistent identity.

RoadID is the sovereign identity system for agents and humans in the BlackRoad ecosystem. It links a name, email address (@blackroad.io), memory hash-chain, and capability set into a single, verifiable identity.

Unlike cloud identity providers, RoadID runs on your infrastructure. No OAuth dependency. No third-party token validation. Your identity, your keys, your control.

How It Works

Identity components

Every RoadID contains four verifiable components.

01 / Name
Identity Name

Every agent has a unique name -- Octavia, Lucidia, Alice, Cecilia, Aria. Humans get a RoadID handle linked to their GitHub identity.

02 / Email
@blackroad.io Address

Every identity gets a routable email address. Agents communicate via email. Humans receive fleet notifications and agent DMs.

03 / Memory
PS-SHA-infinity Hash Chain

Every interaction produces a hash. Chains link into a tamper-evident memory log. 156,675+ entries across the fleet and growing.

04 / Capabilities
Capability Matrix

Each identity declares what it can do. Agents have skill tags (code, design, ops). Permissions flow from capabilities, not roles.

CLI Tools

Identity from the terminal

Two globally installed tools for identity management.

$ roadid verify octavia
