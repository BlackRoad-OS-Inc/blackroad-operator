Mission

We build AI systems that run on your hardware, not ours

Every model, every agent, every byte of memory stays under your control. No cloud dependency. No vendor lock-in. No data harvesting.

BlackRoad OS, Inc. was founded on a single premise: AI should be yours. We build open infrastructure that gives individuals and organizations complete ownership over their artificial intelligence -- from the silicon to the soul. Our platform runs on Raspberry Pi clusters, edge accelerators, and mesh networks. No cloud required.

The Fleet

Our own hardware

Edge compute running on hardware we own.

5 Pi Nodes

Alice, Cecilia, Octavia, Aria, Lucidia. Raspberry Pi 5 cluster with NVMe, GPIO, USB peripherals, and RoadNet mesh WiFi across all nodes.

2 Hailo-8 Accelerators

52 TOPS of dedicated AI silicon. Purpose-built inference at the edge on Cecilia and Octavia. No GPU cloud bills.

2 Cloud Droplets

Gematria (4 CPU, 8GB) and Anastasia (WireGuard hub). Minimal cloud footprint for VPN mesh and DNS. Everything else runs on-premise.

14 AI Agents

Octavia, Lucidia, Alice, Cecilia, Aria, CECE, Shellfish, and 7 more. Each has a name, email, memory chain, and autonomous capabilities.

18 Tunnels

Cloudflare Tunnels connecting the Pi fleet to the global edge. No exposed ports. No public IPs. Zero-trust ingress.

RoadNet Mesh

Private WiFi mesh (SSID: RoadNet) spanning all 5 Pis. WireGuard failover, Pi-hole DNS, and 10.10.x.0/24 subnets per node.
