Features

Autopilot everything

⏱

Cron scheduling

Standard cron syntax. Every minute, every hour, every Tuesday at 3am. You set the schedule, Cruise keeps it.

⚡

Event triggers

Git push, file change, API response, temperature spike. Any event becomes a trigger. Chain them together.

🔌

Webhook listeners

Expose endpoints that fire workflows. Stripe payment received? Deploy triggered. Form submitted? Pipeline starts.

🔒

Self-hosted

Runs on your Pi fleet. Your data never leaves your network. No cloud dependency. No vendor lock-in.

📈

Execution logs

Every run logged with timestamps, duration, exit codes, stdout/stderr. Full audit trail. Searchable history.

🔄

Retry logic

Configurable retries with exponential backoff. Dead letter queues for failed jobs. Nothing gets silently dropped.
