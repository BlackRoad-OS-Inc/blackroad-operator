Features

Revenue infrastructure,
not just a checkout.

⚡
Usage-Based Billing

Track agent invocations, storage consumption, and model usage in real time. Bill exactly what customers use.

🔒
Sovereign Payments

Stripe handles the card processing. You own the subscription logic, pricing rules, and customer data. D1-backed billing state.

📊
Revenue Dashboard

MRR, churn, LTV, cohort analysis. Real metrics from real transactions, not vanity numbers from a third-party dashboard.

🛠
CLI-First Management

Manage subscriptions, issue refunds, generate invoices -- all from br pay. No clicking through web UIs.

🔗
Webhook Events

Subscribe to payment events. Trigger agent workflows on successful charges, failed payments, or plan changes.

🌐
Multi-Currency

Accept payments in 135+ currencies. Automatic conversion, localized pricing pages, and region-aware tax calculation.

CLI
# subscribe to pro plan
$ br pay subscribe pro
  Subscribed to Pro ($19/mo)
  Next billing: April 17, 2026

# check current plan
$ br pay status
  Plan: Pro
  Agents: 8/15 active
  Storage: 12.4/25 GB
  Models: 6/8 enabled
  MRR: $19.00

# view usage breakdown
$ br pay usage --month
  Agent invocations 4,281
  Storage writes 1,092
  Model requests 2,847
  API calls 6,340

# generate invoice
$ br pay invoice --latest
  Invoice #BR-2026-0317 downloaded to ~/invoices/
