How It Works

Describe it. Black Mode handles it.

Write a workflow in plain English. Black Mode parses your intent, assigns agents, schedules execution, and reports results. No code required. No drag-and-drop flowcharts. Just say what you need done.

TRG

Natural Language Triggers

"Every morning at 7am, check all servers and send me a health report." "When a new GitHub issue is opened, triage it and assign to the right team member." Plain English becomes executable automation.

Intent parser / cron / webhook
AGT

Multi-Agent Execution

Complex workflows are split across specialized agents. Alice handles server ops. Octavia handles architecture decisions. Lucidia handles creative tasks. Each agent works in parallel, coordinating through the NATS message bus.

NATS / agent dispatch / parallel
LOG

Full Audit Trail

Every action every agent takes is logged with timestamp, reasoning, and outcome. Review what happened, why, and when. Replay any workflow. Understand every decision. Total transparency.

SQLite / hash-chain / searchable
GRD

Guardrails

Set boundaries for what agents can and cannot do. "Never delete production data." "Always ask before spending more than $50." "Email me before deploying to production." Safety constraints enforced at every step.

Policy engine / approval gates
INT

200+ Integrations

REST / webhooks / mesh bridge
