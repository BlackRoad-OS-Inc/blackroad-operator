Self-Healing

Fleet Autonomy

Automated monitoring and self-healing systems running across every node.

♥

Heartbeat (1m)

Every node sends a heartbeat signal every 60 seconds. Cecilia and Octavia run blackroad-autonomy cron jobs that check stats-proxy and Ollama services, auto-restarting if down.

cron */1 / ~/.blackroad-autonomy/cron.log
⚙

Self-Heal (5m)

Every 5 minutes, heal scripts check service status and restart failed processes. Alice runs a Redis task watchdog every 30 seconds. Lucidia runs brnode heartbeat every 5 minutes.

cron */5 / systemd timers
⚖

Power Monitor

Deployed to all nodes via /opt/blackroad/power-monitor.sh. Checks voltage, throttle flags, CPU temperature, and governor settings every 5 minutes. Logs to /var/log/blackroad-power.log.

cron */5 / conservative governor
