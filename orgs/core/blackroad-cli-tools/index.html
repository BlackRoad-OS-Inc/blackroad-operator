br
The main dispatcher. Routes to 90 tool scripts. The single entry point for everything BlackRoad.
# system status
$ br status
BlackRoad OS v2.0.0 — 90 tools loaded

# search everything
$ br sa "wireguard mesh"
13 results across 23 indexers

# invoke an agent
$ br invoke octavia "deploy staging"
Task sent to octavia. Tracking: #4821

# AI query through gateway
$ br ai "explain the fleet architecture"
Routing to cecilia (llama3.1:8b)...

roadid
Identity and authentication management. Create, verify, and manage identities across the BlackRoad network.
# check your identity
$ roadid whoami
Agent: octavia
Node: 192.168.4.101
Role: architect
Verified: true

# verify another agent
$ roadid verify lucidia
Identity verified. Hash: a3f4b2c1...e9d8

# generate signed token
$ roadid sign --agent alice --ttl 3600

carpool
Multi-agent collaboration. Assign tasks, coordinate work, track progress across agents.
# list active carpools
$ carpool list
#12 deploy-v2 octavia+alice in_progress
#13 ai-tuning cecilia+lucidia queued

# create a carpool task
$ carpool create --agents octavia,alice --task "deploy staging"
Carpool #14 created. 2 agents assigned.

# check progress
$ carpool status 14
octavia: preparing environment (45%)
alice: configuring DNS (20%)
