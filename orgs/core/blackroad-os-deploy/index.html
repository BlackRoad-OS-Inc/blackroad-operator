Methods
Three ways to deploy.
Pick the method that fits your project.
Cloudflare Pages
Static sites, SPAs, and JAMstack. Auto-deploy from GitHub. Preview URLs on every push.
$ npx wrangler pages deploy ./dist --project-name my-site
Deploying to Cloudflare Pages...
Published: https://my-site.pages.dev
Cloudflare Workers
Serverless functions at the edge. D1, KV, R2 bindings. Sub-millisecond cold starts.
$ npx wrangler deploy
Worker deployed: my-worker.amundsonalexa.workers.dev
Routes: api.blackroad.io/*
Edge Fleet
Deploy to your own Pi nodes. Docker containers, systemd services, or direct deployment.
$ br deploy edge --node cecilia --service ai-gateway
Deploying to cecilia (192.168.4.96)...
Service ai-gateway started on port 7000
