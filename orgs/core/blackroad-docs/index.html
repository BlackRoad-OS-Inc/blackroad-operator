Introduction
BlackRoad is an AI platform that runs entirely on your hardware. No cloud dependency, no data leaving your network, no vendor lock-in.
What is BlackRoad?
BlackRoad OS is a complete AI infrastructure platform. It includes 50 AI skills, 29 models across 7 providers, 5 edge compute nodes with 52 TOPS of local inference power, and 90 CLI tools.
Architecture
The platform uses a tokenless gateway architecture. Your agents never see API keys. All provider communication flows through the gateway, keeping credentials isolated at the edge.

Tokenless Gateway

Agents communicate through the gateway at :8787. No API keys in agent code.

Edge Compute

5 Raspberry Pi 5 nodes with 2x Hailo-8 AI accelerators. 52 TOPS total.

WireGuard Mesh

Encrypted tunnels connecting every node. Automatic failover.

Installation
Get BlackRoad running on your machine in under a minute.
Requirements
Node.js 22+, Git, and a terminal. That is all you need.
$ git clone git@github.com:BlackRoad-OS-Inc/blackroad.git
$ cd blackroad
$ npm install && npm run build
$ br status
BlackRoad OS v2.0.0 — 90 tools loaded

Authentication
How identity and auth work in BlackRoad.
BlackRoad uses JWT tokens issued by auth.blackroad.io. The gateway binds to localhost by default. The MCP bridge requires a Bearer token.
Authorization: Bearer <MCP_BRIDGE_TOKEN>

Mesh Network
WireGuard mesh connecting all nodes with encrypted tunnels.
Every node connects to every other node via WireGuard. The hub node (anastasia) coordinates the mesh. All traffic is encrypted. Automatic failover ensures no single point of failure.
