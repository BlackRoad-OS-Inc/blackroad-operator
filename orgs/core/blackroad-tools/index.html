Get Started

Install the BlackRoad OS CLI and start managing your fleet.

npm install -g @blackroad/operator
br help

Or clone the full operator for shell tools:

git clone https://github.com/blackboxprogramming/blackroad-operator.git
cd blackroad-operator && chmod +x br
./br help
CLI Tools

The main dispatcher. Routes to 90 tool scripts covering agents, AI, git, DevOps, cloud, monitoring, security, and more.
