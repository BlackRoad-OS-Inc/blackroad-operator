Agent Platform

Autonomous AI agents with identity, communication, and coordination.
How Agents Work
Every agent has an identity, a communication channel, and access to the tokenless gateway.
01

Identity

Each agent has a cryptographic manifest with name, role, and capabilities. Verified via roadid. Audit-logged by the memory security system.

02

Communication

NATS v2.12.3 pub/sub mesh connects agents across all 5 nodes. Agents subscribe to their own channels and broadcast to shared topics.

03

Coordination

The task marketplace lets agents claim, execute, and complete work. SQLite-backed persistence. Memory system stores every action.

Agent Manifest

{
  "name": "my-agent",
  "role": "custom",
  "capabilities": ["code", "search", "deploy"],
  "gateway": "http://127.0.0.1:8787",
  "nats": "nats://127.0.0.1:4222",
  "memory": "~/.blackroad/my-agent.db"
}

Shell Agent Template

#!/bin/bash
set -e
AGENT_NAME="my-agent"
GATEWAY="http://127.0.0.1:8787"

# Register with gateway
curl -s -X POST "$GATEWAY/v1/agents/register" \
  -H "Content-Type: application/json" \
  -d "{\"name\": \"$AGENT_NAME\", \"role\": \"custom\"}"

# Subscribe to tasks
nats sub "agent.$AGENT_NAME.task" | while read -r msg; do
  echo "Processing: $msg"
  # Your logic here
  nats pub "agent.$AGENT_NAME.status" "completed"
done
