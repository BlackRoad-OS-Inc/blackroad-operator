Deployment Pipeline

Push. Build. Ship.

Push to Gitea
Commit your code and push to Octavia's Gitea instance. The webhook triggers immediately.
git push origin main
Build on Lucidia
GitHub Actions runner on Lucidia picks up the webhook. TypeScript compiles, tests run, assets optimize.
npm run build && npm test
Deploy to Edge
Wrangler publishes the Worker to Cloudflare's global network. DNS routes are already configured.
wrangler deploy
Mirror to GitHub
github-relay syncs from Gitea to GitHub every 30 minutes. Backup and public visibility.
sync-downstream --push
Verify
Health check confirms the deployment is live. RoadChain logs the deploy hash.
br health-check --verify
Cloudflare Pages
Static sites and SPAs. 95+ deployments across 20 domains. Auto-deploy on git push.
Cloudflare Workers
Edge compute for APIs, auth, billing, search. Sub-millisecond cold start globally.
Docker Swarm
Container services on the Pi fleet. ARM64 images deployed to Octavia and propagated.
