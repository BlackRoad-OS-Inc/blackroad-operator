Install
Up and running in 30 seconds.
Clone the repo, run the CLI. No package managers, no build steps.
# clone and install
$ git clone git@github.com:BlackRoad-OS-Inc/blackroad.git
$ cd blackroad && npm install && npm run build

# verify installation
$ br status
