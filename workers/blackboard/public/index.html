Add BlackBoard to any site

One script tag. No cookies. No GDPR banner needed. Under 2KB. Tracks pageviews, clicks, conversions, UTM attribution, and CRM contacts.

<script src="https://bb.blackroad.io/bb.js"></script>

Track custom events

Use the JavaScript API to track conversions, signups, and any custom event.

// Track a custom event
bb.track('button_click', { button: 'hero-cta' });

// Track a conversion with revenue
bb.convert('purchase', 299, 'USD');

// Identify a contact (CRM)
bb.identify({ email: 'user@example.com', name: 'Jane' });

// Track signup with attribution
bb.track('signup', { plan: 'sovereign', free_month: true });

Email tracking pixel

Add to any email template for open tracking.

<img src="https://bb.blackroad.io/px?cid=CONTACT_ID&campaign=CAMPAIGN_NAME" width="1" height="1">

Click tracking for links

Wrap any URL to track clicks with attribution.

https://bb.blackroad.io/r?url=https://auth.blackroad.io/signup&src=email&campaign=launch
